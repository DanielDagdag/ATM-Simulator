<h1> ATM Console Project </h1>
───────────────────────────────────────────────

<font size="4"><b>Introduction:</b></font>  
The ATM Console Project is a simulation of a real Automated Teller Machine (ATM)  
system built using Java. It demonstrates basic banking operations such as  
**Balance Inquiry**, **Deposit**, and **Withdrawal**.  
This project focuses on applying programming fundamentals like  
conditional statements, loops, and object-oriented concepts.

───────────────────────────────────────────────
          <h2> Key Features </h2>
───────────────────────────────────────────────

• 🔐 PIN Verification  
• 💰 Balance Inquiry  
• 💳 Deposit   
• 🔄 Withdrawal  
• ⚙️ User-Friendly Console Interface
